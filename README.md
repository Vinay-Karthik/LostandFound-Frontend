# CampusTrack — Frontend Client

CampusTrack responsive web application built with **React 18** and **Vite**.

## 🛠 Tech Stack
- **Framework:** React 18, Vite
- **Routing:** React Router DOM 6
- **Styling:** Custom Glassmorphic Dark/Light CSS design system with CSS Variables
- **Icons & UI:** Lucide React, Canvas Confetti
- **HTTP Client:** Axios with JWT interceptors
- **Real-Time:** SockJS & @stomp/stompjs (WebSockets)
- **Charts:** Recharts

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- NPM

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Runs locally at `http://localhost:5173`.

### Production Build
```bash
npm run build
```
